# Artifacts Description

## Описание артефактов проекта

Папка `artifacts/` содержит артефакты, автоматически создаваемые в процессе индексации и работы сервиса SemDatasheet.

Артефакты используются для:

* ускорения повторного запуска сервиса;
* сохранения результатов индексации;
* хранения retrieval индексов;
* восстановления состояния search pipeline без повторной обработки PDF.

---

# Содержимое папки

## faiss.index

FAISS индекс для векторного поиска.

Содержит:

* эмбеддинги текстовых чанков;
* индекс ближайших соседей;
* данные для semantic retrieval.

Используется библиотекой:

* faiss-cpu

---

## vector_meta.json

Метаданные векторного индекса.

Содержит:

* соответствие embedding ↔ chunk_id;
* служебную информацию retrieval pipeline.

---

## bm25.pkl

Сериализованный BM25 индекс.

Используется для:

* keyword retrieval;
* lexical search;
* hybrid ranking.

Создаётся с использованием:

* rank_bm25
* pickle

---

## chunks.json

Сохранённые текстовые чанки.

Для каждого чанка сохраняются:

* filename;
* page;
* chunk_id;
* text;
* metadata.

Используется:

* при поиске;
* для восстановления retrieval pipeline;
* для выдачи результатов API.

---

## manifest.json

Файл состояния индексации.

Содержит:

* количество документов;
* количество чанков;
* параметры chunking;
* название embedding модели;
* параметры hybrid search;
* информацию о версии приложения.

Используется для:

* проверки совместимости артефактов;
* диагностики состояния индексов;
* health-check endpoint.

---

# Особенности хранения

В репозитории сохраняются только:

* небольшие retrieval индексы;
* демонстрационные артефакты;
* lightweight metadata.

Крупные модели и массивные индексы не включаются в репозиторий.

---

# Автоматическая генерация

Артефакты создаются автоматически:

* при первом запуске сервиса;
* при отсутствии индексов;
* после переиндексации PDF документов.

---

# Повторное использование

При повторном запуске:

* сервис автоматически загружает существующие артефакты;
* повторная индексация не требуется;
* startup time существенно уменьшается.

---

# Безопасность

Папка `artifacts/` не содержит:

* персональных данных;
* секретов;
* токенов;
* конфиденциальной информации.

Все артефакты формируются только на основе открытых технических PDF-документов.
